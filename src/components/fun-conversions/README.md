# 趣味换算卡

负责把当前显示收入换算为商品数量，维护本卡片的内容、样式与实时/历史标题。它不计算工资、不读取存储、不访问其他卡片，也不启动定时器。

## 修改入口

| 任务 | 文件 |
| --- | --- |
| 商品名称、图标和示例价格 | [items.json](items.json) |
| 本卡片的结构与现有 ID | [view.html](view.html) |
| 数量、标题和挂载清理行为 | [index.js](index.js) |
| 本卡片专属排版和响应式规则 | [style.css](style.css) |

单价使用以元为单位的正数；`income` 是主流程提供的当前显示金额数值，不是带货币符号的字符串。商品配置的类型与价格由源码检查验证。

`style.css` 的 33 个命名片段在构建时放回原有位置，媒体查询仍由 [page.html](../../page.html) 的原上下文包裹。不能把整份文件直接加载或搬到样式表末尾。公共卡片、字体、主题与启动样式继续留在模板中；这些属于共享能力，不在本卡复制一套。

## 输入与方法

总装入口传入 `root`、`items` 与现有 `writeText` 助手。根节点为 `#funSummaryCard`，组件只查找其中的 `.fun-title` 与 `.fun-fact`。

- `mount()`：创建数量节点，重复调用不重复挂载。
- `update({ income })`：接收当前显示收入，保留 `Math.floor(income / price)` 与同值不写入规则。
- `setContext(atLive)`：更新本卡实时/历史标题。
- `destroy()`：清除本组件节点引用与列表，可重新挂载。

收入和时间状态由原主流程提供；不直接访问全局 `dom`、`CONFIG`、时钟或浏览器存储。销毁沿用原页面生命周期，不新增独立调度器或事件总线。后台暂停与浏览器缓存返回不会触发销毁，原节点和状态继续使用。

## 生成与定位

维护时只编辑 `src`。运行 `npm run build:push` 生成独立 Develop 与 Push；完整同步沿用 `npm run release:prepare`。用户只需一份 HTML，运行时不读取本目录。

生成文件中的错误行可以通过 `npm run source:locate -- <行号>` 回查源文件。`--check` 会拒绝过期生成物、缺失或重复片段、循环及越界引用，不会自动覆盖手改结果。
