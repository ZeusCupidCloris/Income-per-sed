## 分段核对

对旧、新 Develop 各制作内存服务诊断副本，用现有 Acorn 解析器只在目标函数入口及其格式化表达式处计数，原 formatter 的返回值不变。Edge / WebKit 共四个独立页面，串行运行；受控时钟用于状态读数断言，不是原生时钟耗时基准。产品文件没有写入探针，也未改变原正式测试的计时配置。

每页依次覆盖实时、同秒增加 200 毫秒、历史暂停、播放、再次暂停、返回中、恢复实时七段。每个引擎旧、新均观察 71 次顶部同步，格式化调用分别为 213 / 142；旧版每次为 displayedDate 两次、liveNow 一次，修改后各一次。旧版两次 displayedDate 的输入和结果相同；新旧所有被观测同步均核对可见时间、标签、datetime 与本次格式化输入/结果一致，实时锚点使用独立实时值。

除返回中间帧外，两个引擎各六段快照的新旧读数与标签完全相同。同秒 200 毫秒变化保留，未误用上一帧结果。返回中间帧的两页实际输入时刻不同，原始数据保留，不能把本诊断写成逐帧运动等值对照；这里只验证各自本次读数内部一致。运动算法的等值边界由源码精确证明及本轮原完整动效用例检查共同承担，不猜测该采样差异的原生原因。
