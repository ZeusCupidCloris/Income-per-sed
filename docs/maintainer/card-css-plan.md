# 逐卡片整理重复 CSS

目标是减少样式覆盖与维护歧义，不改变 RC37 字体、字号、字重、布局、配色、圆角和交互。每批只处理一张卡片或一个共同职责，经独立分支与 PR 验证后合并，不顺手修改计算、存储或动画算法。

## 批次顺序

| 顺序 | 对象与主要选择器 | 本批整理内容 | 必须保留的状态 |
| --- | --- | --- | --- |
| 1 | 每小时收入 `#incomeSettingsCard` | 合并标题、金额、单位、说明和编辑图标的重复声明，固定唯一生效来源 | 金额隐私、悬停、按压、键盘聚焦、展开隐藏原卡片与关闭恢复 |
| 2 | 已工作 `#workedTime`、`#workedSub` | 整理数字/单位基线和辅助文案规则，避免覆盖到主收入滚轮 | 开工前、工作中、午休、完成、休息日、实时剩余时长与历史日期 |
| 3 | 月累计 `#monthSummaryCard` | 合并累计、预计、月份说明和日历提示的层叠规则 | 三种工资、跨月、长金额、隐私、日历超出覆盖范围 |
| 4 | 趣味换算 `#funSummaryCard` | 统一项目、图标、数量与文案规则；密度控制的状态变化单独核对，不用固定高度遮掩差异 | 零值、多位数量、窄屏、密度 normal/compact/critical；定位旧 3 像素行距差的初始化边界 |
| 5 | 工作进度 `#scheduleSettingsCard` | 整理标题/剩余/百分比、两段轨道及标签的重复覆盖 | 午休空档、零与满进度、回溯、恢复接管、可编辑反馈和自定义时段 |
| 6 | 回溯 `#historyQuickPanel` | 合并桌面/手机面板、按钮和日期滚轮的散落规则，保留拨盘专用样式 | 错误时间、键盘、触摸、禁用/播放/暂停/返回、窗口及可视视口变化 |
| 7 | 两类设置 `#settingsDialog` | 工资与工时分别整理，再提取确实相同的控件角色；不创建万能面板样式 | 草稿、校验、取消确认、隐私解锁、备份比较、展开收回与减少动画 |
| 8 | 主收入/任务仪表与顶部工具 | 最后核对主仪表材质、机械滚轮、码表和顶部控件，风险最高，分别成批 | 长金额、进位、时薪与计时状态、主题交接、网格、专注和隐私 |

前四批优先于主仪表。主仪表多层规则可能分别控制材质、主题与机械运动，不能仅凭“同名选择器出现多次”就合并。

## 每批操作

1. 用 CSS 解析或浏览器 CSSOM 列出目标选择器及声明位置，记录来源顺序、特异性、媒体条件和最终生效值。
2. 保存目标卡片与相邻卡片在既定状态下的计算样式和截图，检查是否存在跨卡片选择器。
3. 先删不存在的选择器和可证明失效的相同声明，再归并最终权威规则；保留必要的条件覆盖，不扩大选择器作用域。
4. 只在多个实际使用点完全同义时提取共享变量。维持独立的控件、内容和材质角色，不把所有差异压进一个组件类。
5. 重新生成 Push，复测本卡片与相邻卡片，记录源码和发布文件字节差；无收益或出现外观偏差时撤销本批自己的调整。

## 每批验收

- 浅色/深色，320/390/854/1440 像素；关键卡片再覆盖极矮横屏与长内容。
- 常态、悬停、聚焦、按压、禁用、错误及开合中间帧；减少动画和强制高对比度不能遗漏。
- 比较几何、计算样式和截图；不更改原像素容差、不增加重试、不以更新基线掩盖清理造成的差异。
- 真实视觉没有变更时，原则上截图基线不变。浏览器版本或字体差异先分离诊断。
- 记录 Develop/Push 字节差、重复声明减少项和相关测试结果；不承诺未经测量的压缩百分比，也不把删行数当作流畅度。

当前已有工作日、月历、费率缓存和整秒普通读数采样。本轮 CSS 整理不再引入第二套缓存，不重写这些已存在的优化。

### 清理边界

- 只移除相同选择器、相同条件下被后续有效声明覆盖的旧声明，以及已无 HTML 或脚本引用的旧类规则。未仅凭选择器重复出现就归并整块样式。
- 仪表批次包含 117 条已无引用的声明；保留可能含有活动选择器的混合规则。两项无法同时用 Edge、WebKit 确认支持的带前缀声明原样保留。
- 每批均验证 `<style>` 之外的字节完全不变，保留原有脚本、页面结构、自定义属性、关键帧及必要条件覆盖。小组件、产品依赖、测试配置和视觉基线不变。
- Push 由 Develop 重新生成。手册仅同步文件校验值，Word 渲染仍为九页，前八页像素一致，仅第九页校验值变化。README 三张展示图及来源记录同步到本地候选文件，不修改测试截图基线。

### 验收进度

八批共 165 次局部场景对照通过计算样式、几何与完整截图检查。最终全页 59 场景也已通过原始元素样式、真实文字边界、完整绘制后的布局及完整截图对照。57 项既有配套检查、137 文件索引、构建和交付校验通过；连续两次重建的六个文件逐字节一致。Edge 全量 272 项通过，包含原有视觉与布局 8 项，无失败或跳过；WebKit 全量 179 项通过，4 项既定跳过。两种浏览器均未启用测试重试，无失败或 flaky 结果。

WebKit 四项跳过分别是 Develop/Push 拨盘原生触摸拖动，以及设置面板对角手势和弱化行纵向手势；它们依赖 Chromium CDP 注入，在 Edge 中均实际执行通过。WebKit 其他模拟触摸检查不受影响，仍不代表实体手机已验收。

附加截图工具曾出现被跳过绘制的背景文字，而计算样式和布局一致；失败证据保留，不用更新基线或放宽容差消除。最终辅助对照分别检查原始计算样式与布局，再让两侧相同地完整绘制后比较截图，禁止脚本执行、要求 DOM 不变，不遮挡或忽略区域。文本节点没有独立的 CSS 宽高与偏移，工具比较其真实边界及字体，避免把浏览器返回的匿名文本盒缓存值当作元素样式；所有元素计算样式仍完整核对。像素颜色阈值 0.2、允许差异像素数 0；极少数原始通道舍入差另行保留，不声称原始 PNG 字节相同。原有浏览器测试不使用这套额外绘制处理，原视觉容差和截图基线均未修改。

趣味换算原有 8px 与 critical 状态 5px 行距均保留。初次采样未统一时钟和展开完成点，曾落在不同初始化状态；改为固定时间、字体和展开就绪后，原版自身复测与候选版在 320/390/854/1440 像素均一致。记录保留初始化与稳定后结果，本轮没有修改密度算法，也未用固定高度掩盖差异。
