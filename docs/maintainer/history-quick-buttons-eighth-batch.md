# 快速回溯按钮接线迁移

从[第七批候选](history-time-input-seventh-batch.md)继续，将步进、今日零点、播放／暂停和返回实时的点击分发移入[按钮模块](../../src/components/history-quick-buttons/README.md)。面板开关、按钮反馈、时间轴状态、动画和键盘快捷键保留原实现。本地验证，不升版、上传、部署或替换桌面。

对同一份非法时间草稿先点播放、再点返回实时：前者必须保留错误并停在原历史时刻；后者必须清除草稿并回到实时。另覆盖有效状态下的步进、今日零点和播放／暂停。

## 验证

- Edge 和 WebKit 各通过 13 项专项，覆盖非法草稿拦截播放后返回实时、正常步进和今日零点、播放暂停、拖动及按钮反馈、两份单 HTML 离线打开。
- Edge 原有 8 项视觉检查通过，未更新截图基线。快速检查含 77 项自动检查与 217 文件索引；两次重建的 6 个文件一致。
- Develop 对照确认差异仅为按钮接线。三张 README 预览及小组件不变；手册仅更新网页校验值，第九页已核对。

此前 Windows WebKit 缩放崩溃未复测，不以本批专项替代全量或真机验收。预览、回退存档及原始日志留在本地。
