# 全局 CSS 候选审计

本地基准为 `c125995`，承接[八批卡片清理](card-css-plan.md)。本轮逐项审查剩余 37 条非自定义属性、非关键帧覆盖候选，删除 33 条已被相同选择器、相同条件下后续规则覆盖的声明，保留 4 条兼容声明。不改 RC37 外观、页面结构、计算、存储或动画算法，不引入产品依赖，版本仍为 2.7.2。

这是未发布的本地维护候选。未上传 GitHub、创建 PR、合并 main、部署 Pages 或替换桌面文件；真实手机与真实整夜验收继续暂缓。

## 保留项

| 选择器 | 声明 | 决定 |
| --- | --- | --- |
| `body` | `min-height:100vh` | 保留渐进兼容链，不以当前引擎支持新单位为由删除回退 |
| `body` | `min-height:100svh` | 同上；保留 `vh → svh → dvh`，只移除重复的另一次 `dvh` |
| `.status-row` | `-webkit-backdrop-filter:blur(12px) saturate(1.02)` | 不满足两种审核引擎共同支持的删除门槛，保留前缀兼容声明 |
| `.fun-card` | `-webkit-backdrop-filter:none` | 同上，即使新旧值相同也不在本轮强行删除 |

解析器剩余的非变量、非关键帧候选由 37 条降为上述 4 条。候选不等于无用代码；自定义变量、关键帧和必要条件覆盖保持原样。

## 下一步建议

该建议已由[自定义变量引用审计](css-variable-audit.md)承接；该轮仅审计，未删除变量或修改本轮的候选页面。以下保留当时的建议。

先建立自定义变量引用清单，区分主题覆盖、角色别名、脚本动态写入和真正无引用的值。第一步只审计，不批量改名或替换；对无法解析的动态写入按仍在使用处理。继续保持当前字体与动效，算法改动只针对重新采样确认的实际热点。
