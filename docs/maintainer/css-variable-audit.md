# 自定义变量引用审计

本地基准为 `4a872fd7867ec853e96ca4c1232f1ade4aac6cce`，承接[全局覆盖声明审计](global-css-audit.md)。本轮只建立定义、消费路径、别名依赖及脚本读写清单，不删除变量、不重命名、不替换值，继续保留 RC37 字体、布局和动效。产品仍为 2.7.2 / 20261023.1。

Develop、Push、小组件、Word 手册、校验清单和发布清单六个文件均与基准逐字节相同。未上传 GitHub、创建 PR、合并 main、部署 Pages 或替换桌面文件；真实手机与真实整夜验收继续暂缓。

## 范围与方法

- 解析 HTML 后核对全部 19 个样式块、4 个脚本块；页面没有内联 `style` 属性。样式使用已有 CSS 解析器，脚本使用已有 JavaScript 语法树解析器，不引入依赖。
- 区分普通 CSS 消费、变量别名、嵌套回退、过渡属性目标、关键帧写入、32 项 `@property` 类型注册，以及脚本的直接和间接读写。
- 从普通样式或脚本读取反向追踪别名依赖。条件与选择器采用保守并集：有消费路径就保留，不宣称每个分支在所有状态下均实际生效，不跨作用域合并同值变量。
- 动态入口逐项核对。有限循环展开为实际名称；缓存读取、延迟写入和固定的普通属性复制分别记录，不将无法解析的表达式直接当作无引用。
- 浏览器观察只补充静态证据；未在有限场景中观察到，不等于无用。读写记录会影响耗时，因此不把本轮观察用作性能测试。

| 项目 | 数量 | 含义 |
| --- | ---: | --- |
| 自定义变量名 | 340 | 包括已定义、脚本提供以及带回退或缺少定义的消费入口 |
| CSS 定义名称 | 305 | 共 688 处声明；多主题、条件和局部定义分别计数 |
| 有消费路径的名称 | 284 | 保守保留，不因当前页面未显示而删除 |
| 未找到消费路径的已定义名称 | 56 | 共 99 处声明；本轮全部保留，等待分组删除对照 |
| 脚本写入名称 | 71 | 其中 28 个没有 CSS 普通定义，由运行时提供；不算缺失定义 |
| 带主题定义的名称 | 112 | 与其他分类可重叠，不能把主题覆盖当作冗余 |

另有 `--theme-ink-noop` 是主题文字过渡使用的占位属性名，不是待定义的样式变量，也不计入 340。它用于避免原生颜色过渡与主题文字动画互相叠加，不因没有变量定义而删除这段逻辑。

## 必须保留的入口

| 入口 | 核对结果 |
| --- | --- |
| `readPalette` | 间接读取三个 `--ambient-grid-*` 调色值；过渡时还直接读取对应的类型注册变量 |
| `readCssTime` | 间接读取七个动效时长；例如 `--motion-intro` 没有 CSS `var()` 引用，但脚本确实读取，必须保留 |
| `setStylePropertyIfChanged` | 两处缓存读取与一处延迟写入使用调用者传入的同一名称；调用者名称均为字面值，已纳入清单 |
| `setVisualStyle` | 接收五个滚轮变量及普通的 `visibility` 属性；保留滚轮角度、深度、缩放、透明度和明暗 |
| `--entry-card-${key}` | 两个有限循环展开为 `left`、`top`、`width` 三个名称；写入及清除共同构成面板定位，不补无意义默认值 |
| `createSettingsMirror` | 固定复制布局与排版的普通属性，不读取任意自定义变量；不把这处通用循环理解为未知变量消费者 |
| `--r40-space-3`、`--r40-space-4`、`--r40-radius-secondary` | 仍有消费路径，不因同前缀的其他变量已过期而整组删除 |

六个入口共核对 10 处需要展开或人工追踪的表达式，清单中无未决的动态名称。这里的保留结论包括缓存和复制行为，不表示每次读取都直接参与绘制。

## 分组清理候选

52 个名称没有任何消费引用；另外 4 个金属色只被未使用的别名引用。所有 56 个候选均没有脚本名称提及、读写操作或类型注册。下表只列下一步清理范围，不表示已经删除。

| 建议顺序 | 分组 | 名称 | 声明 | 验证重点 |
| --- | --- | ---: | ---: | --- |
| 1 | 旧间距与圆角 | 14 | 25 | 主界面、两类设置、日期估算与回溯的桌面及窄屏对照 |
| 2 | 旧性能与动效参数 | 7 | 7 | 保留现用性能降级和动效时长；只删定义，不碰算法 |
| 3 | 仪表、显示和颜色旧参数 | 27 | 55 | 明暗主题、金额位数、表盘及机械滚轮，不改实际配色 |
| 4 | 旧金属别名链 | 8 | 12 | 以四对依赖为单位核对，不误删现用材料变量 |
| 合计 | 待后续分批验证 | 56 | 99 | 每批独立检查点，不更新截图基线或放宽容差 |

### 第一批 旧间距与圆角

`--r40-radius-control`、`--r40-radius-hero`、`--r40-radius-micro`、`--r40-radius-nested`、`--r40-radius-primary`、`--r40-space-1`、`--r40-space-2`、`--r40-space-5`、`--r40-space-6`、`--radius-md`、`--release-detail-gap`、`--release-module-gap`、`--settings-field-radius`、`--settings-wheel-radius`。

这批优先级最高：没有入向消费引用，涉及 25 处定义，不需要改脚本或现用文字角色。删除时仍需计算样式、文字边界及截图验证；允许改变的只有清单内自定义属性本身，普通绘制属性及布局必须保持一致。

### 第二批 旧性能与动效参数

`--ease-data`、`--ease-enter`、`--performance-backdrop-blur`、`--performance-card-blur`、`--performance-decoration-blur`、`--performance-decoration-opacity`、`--performance-dialog-blur`。

这些旧变量没有消费路径，不等于页面的性能控制逻辑可以删除。不得连带改动当前仍有脚本读取的 `--motion-*`、背景降级类或减少动态效果分支。

### 第三批 仪表 显示和颜色旧参数

`--accent-blue-soft`、`--amount-density`、`--decoration-1`、`--decoration-2`、`--decoration-3`、`--dial-face-muted`、`--dial-red`、`--dial-shell-dark`、`--dial-shell-light`、`--dial-shell-mid`、`--flip-bg`、`--glare-boost`、`--glass-highlight`、`--glass-shadow`、`--month-data-accent`、`--needle-red-deep`、`--shadow-sm`、`--status-strip-border`、`--tier-three-border`、`--tier-three-shadow`、`--workshop-brass-light`、`--workshop-metal-dark`、`--workshop-metal-light`、`--workshop-metal-mid`、`--workshop-paper-deep`、`--z-dial-face`、`--z-dial-subhand`。

`--dial-red` 虽无消费路径，但与下述参考线缺失颜色问题相关的设计判断应分开处理；不能为了让它重新有引用而随意接入现用样式。`--amount-density` 有十处定义，不能将十处定义误记为十个变量。

### 第四批 旧金属别名链

`--metal-deep`、`--metal-highlight`、`--metal-mid`、`--metal-shadow`，以及对应的 `--pocket-metal-deep`、`--pocket-metal-highlight`、`--pocket-metal-mid`、`--pocket-metal-shadow`。

前四个名称不是零文本引用，而是各自只被后一组别名引用；后一组又没有消费入口。因此整条链均列为候选，而不是先删上游留下悬空别名。

## 缺少定义的消费入口

六个入口存在明确回退，原样保留：`--accent-red`、`--error-color`、`--history-sheet-dismiss-y`、`--ips-ui-font`、`--material-panel`、`--quick-motion-ms`。它们并不因缺少定义就必然形成视觉错误；本轮不为清单整齐而新增定义或替换为常量。

另有一处确认的问题：`.dial-real-marker > span` 的边框和背景使用 `--dial-magma`，但页面没有定义、类型注册或脚本写入，也没有回退。对应 Develop 基准行 1752、1759。

在回溯暂停、关闭快速回溯面板后，两种浏览器及两种版本均读到参考线父层透明度为 0.2，但子元素边框为 `none / 0px`、底色透明。仅在隔离浏览器中临时补入一个测试颜色后，边框变为 `solid / 1px`，移除后完整恢复。这证明两条颜色声明失效；不将其描述成整个表盘或收入计算错误。

本轮没有将测试颜色写回产品，也没有决定最终修复颜色。建议单独做小范围修复预览，与纯删除提交分开验证，避免悄悄改变现有观感。
