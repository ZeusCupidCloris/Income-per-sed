- 趣味换算卡在专注模式隐藏时可用宽度为 0，旧实现用 1px 继续比较。连续两次会进入最紧凑状态，重新显示时又把整列分配宽度当作内容宽度，造成 390px 整页截图有时差 3px。现在忽略不可测宽度，并使用图标和文字的实际宽度；阈值、行距和截图基线都不改。
