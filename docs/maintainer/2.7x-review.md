## 已交付版本

### 2.7.0：整合体验与保存安全

[版本说明](../releases/v2.7.0.md)与[验收](../acceptance/fourfile-20261021.md)，产品合并 `72a6d62`。

- 工资、工作时间和快速回溯成为完整展开面板，沿用 RC37 字体与机械显示；正常视口不靠多层下拉，极矮窗口或键盘压缩视口保留内部滚动和可用的保存区。
- 统一开合与编辑提示；回溯区分播放、暂停、返回实时和关闭，整页标题及辅助文字跟随所看日期/月，避免历史数据仍被标作“今日”。
- 每种工资模式独立保留草稿；关闭前可确认放弃，刷新后恢复需确认，恢复草稿不等于已保存。
- 工资、工时和日历可以一起备份；导入先比较实际变化并保护工资金额，取消、并发编辑和写入失败有相应保护。
- 任务码表显示“任务计价 / 计时中 / 已暂停”，表冠清空后有五秒撤销；保留默认示例收入，未强制首次进入显示“待设置”。
- 手册改为九个用户场景章节，解释实际操作以及午休轨道、即时计算、费率锁定、撤销和导入对比的设计考虑，更新配图。
- 同步唯一 Develop 源、自动生成 Push、小组件交付元数据及校验清单；小组件业务和布局不重新设计。
- 修复生成时经典脚本压缩导致跨脚本全局变量重名、一个日期回溯入口漏删开发诊断调用；构建验证相应增加检查。
- main 复检曾拦下跨动画帧测试时钟竞态；PR #57 改为在受控动画帧上比较，产品文件不变。没有靠提高像素容差掩盖失败。

随后 `ff82dda` / PR #59 只更新 `.editorconfig`、`.gitattributes`、`.gitignore` 和用途声明，改善编码/换行、仓库输出排除及使用说明，不改网页功能。

### 2.7.1：减少重复工作

[版本说明](../releases/v2.7.1.md)与[验收](../acceptance/fourfile-20261022.md)，产品合并 `2773d1b`。

- 收入设置展开时隐藏来源卡片，关闭后恢复，形成与工作进度一致的原位展开体验；隐私、手机视口和减少动画状态一并检查。
- 删除已经退出界面的下拉控制器、样式和无效监听，不增加产品依赖。
- 已工作和剩余时间只在整秒或状态改变时重新格式化；关闭的快速回溯面板不再反复同步内部文字。核心指针、机械滚轮、回溯运动仍连续，不用降动画帧率换取省事。
- 移动回溯测试明确区分取消拖动、下滑关闭和按钮关闭，并等待真实入场/回弹完成；没有改用户手势或放宽阈值。
- 四文件、手册和预览同步；小组件仅改交付标识。受控采样证明重复处理次数下降，没有证明所有设备获得固定提速或内存下降。

### 2.7.2：全天拨盘与输入可靠性

[版本说明](../releases/v2.7.2.md)与[验收](../acceptance/fourfile-20261023.md)，产品合并 `5eeff46`。

- 快速回溯增加全天拨盘，区分上午、下午、实时位置和不可选区间；日期轮换日，拨盘调整日内时间，中心时间可直接输入时分秒。
- 调整播放与返回实时的权重和位置，鼠标、键盘入口共用限时交接，减少按下后的等待；保留非工作时段定位但不计入额外工作收入。
- 无效或未来时间持续显示错误并阻止提交，直到修正或明确放弃；Esc 取消直接编辑。
- 修复失焦到提交之间的页面刷新覆盖有效输入：待提交的直接输入持续保留到提交或取消，新增延迟提交回归先证明旧版失败，再验证修复。
- 拖动复用坐标，滚动、窗口或可视视口变化后使缓存失效；移除旧追针启动分支和失效读数样式，不额外建设第二套已有的日历/费率缓存。
- 同步四文件、手册五张插图、首页预览与来源哈希。小组件依旧只改元数据，正式主页及其他卡片视觉基线保留。

完整业务回归最后一次记录为 Edge 288 项通过；WebKit 192 项通过、4 项既定驱动能力跳过、3 项失败。之后的持久化专项和诊断不能把该历史报告改成全量通过。已发布版本当时的 CI/Pages 通过也不能证明当前候选通过；2.7.1 main 曾有一项准备步骤重试，保留原记录，不统一描述成所有交付均无重试。

自定义逐帧采样属于测试附加的观测代码，并非用户页面常驻功能。本次纯 JS 记录仍崩溃、无自定义循环十二轮未崩溃，不能简单锁定某个布局读取 API；观测调度、追踪和实际渲染的边界仍待区分。相同症状在最后一批金属别名删除之前的本地基准就出现过，不足以归因于那十二处定义，也不能据此证明已发布版普通用户流程一定受影响。

真实手机和真实整夜验收仍按要求暂缓，浏览器触摸或后台模拟不作为替代。当前最紧要的不是继续删 CSS，而是识别崩溃对自定义观测和追踪的依赖；处理清楚后，重新执行完整关卡，再按独立 PR 决定是否交付。

后续 2.7.x 的顺序应是：先稳定性与完整回归，再确认参考线预览和同步交付，最后继续选择器/关键帧只读审计及有耗时基准的测量/写入合并。只有确认实际热点后才改计算或运动算法，不重复建设已有缓存，不把维护性删减当成未经测量的提速。
