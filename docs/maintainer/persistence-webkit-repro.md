后续[单因素对照](webkit-factor-controls.md)已捕获五次恢复窄屏崩溃，包括同页首轮和不返回实时的流程；采样与主题组有待继续缩减，根因仍未确认。以下保留本轮原始结果，不以诊断组替代完整验收。

本地基准为 `3a354bd`，承接[金属别名与完整回归记录](css-variable-metal-alias.md)。本轮仅调整测试并排查稳定性，不继续精简产品源码、不改字体、动画或算法，不升级版本，不上传 GitHub、部署 Pages 或替换桌面文件。真实手机及真实整夜验收仍暂缓。

## 持久化测试

原 `release-behavior.spec.js` 在一个 45 秒用例中依次执行三种工资模式。拆为固定月薪、全年均摊、固定日薪三个独立用例，Develop 与 Push 各三项。每例继续使用原有浏览器页面夹具和 45 秒上限，不新增超时豁免。

AST 对照确认原有 19 条初始化、操作和断言语句按顺序保留，其他六个参数化测试调用不变。每种模式仍经过打开设置、选择、输入 `2600`、保存、刷新、重新打开、回读 `2600.00`、关闭、检查进度及脚本错误；额外检查按钮选中状态与事务存储中的模式。文件内既有“三模式 × 工作日/休息日 × 双版本”连续切换计算对照保留且本轮通过，不把独立用例写成跨窗口状态移交测试。

| 本轮专项 | 通过 | 失败 | 跳过 | 重试 |
| --- | ---: | ---: | ---: | ---: |
| Edge：整个发布行为文件 | 19 | 0 | 0 | 0 |
| WebKit：整个发布行为文件 | 19 | 0 | 0 | 0 |

六项持久化用例在 Edge 各约 4.60–4.73 秒，在 WebKit 各约 14.76–15.02 秒。结果支持原流程三种模式共用总预算不足的解释，不代表所有工资存储边界已全部验证。原完整回归的两项超时仍保留在当时报告里，不能用本次专项通过改写历史失败。

测试初稿曾尝试串行移交整份浏览器存储，先出现新增断言取错事务字段，修正后又携带了上个窗口的有效写入租约，影响新窗口保存。两次初稿结果完整保留，未当作产品回归结论。最终采用独立页面，不移交租约、不绕过产品的多窗口协调；符合 [Playwright 的隔离测试建议](https://playwright.dev/docs/browser-contexts)。

## 缩放排查

沿用 Windows、Playwright 1.62.1、WebKit 26.5；未修改驱动、依赖或浏览器启动参数。业务时间固定，动画回调和 ResizeObserver 保持运行。长金额使用十亿月薪、全年 12 个工作日；缩放路径为 390 → 768 → 390，包含回溯、滚轮、主题切换和返回实时。

2026-10-26 表述更正：双引擎空白页核对确认 `clock.setFixedTime` 会包装 Date、定时器、RAF 及 performance；持续运行的回调不能写成接口完全原生。原测试中的对应注释也有同样表述问题，本轮不修改该测试。历史通过、超时和崩溃仍有效保留，尚未证明时钟包装是原因。见[追踪边界与时钟核对](trace-boundary-audit.md)。

| 有界实验 | 预定上限 | 本次结果 |
| --- | ---: | --- |
| 原始失败用例单次控制，原断言不改 | 1 | 1 项通过，无重试 |
| 同一页面连续缩放，保留追踪及只读采样 | 12 轮 | 12 轮完成，无崩溃 |
| 同一浏览器内新建上下文，保留追踪及只读采样 | 6 轮 | 前 2 轮完成，第 3 轮崩溃即停止，其余 3 轮未执行 |
| 删除其他卡片和业务逻辑的滚轮候选页 | 12 轮 | 12 轮完成，无崩溃；不能称为有效最小复现 |

第三组位于第二组之后，共用一个浏览器进程；尚未证明无需前置负载也会失败，不能直接归因于新建上下文本身。该组已完成的两轮保留金额边界、滚轮运动、实时状态和进度游标偏差小于 2.5 像素检查。诊断路径不是完整原用例的逐字复制，单次控制才直接执行原文件。

新失败有独立的页面 `crash` 事件，发生于第 3 轮恢复 390 像素时。追踪显示 `setViewportSize` 在约 33 毫秒后以 `Target page, context or browser has been closed` 结束；此前原失败是在恢复窄屏协议完成后，下一次阶段标记求值收到 `Target crashed`。两者同处恢复窄屏阶段，但协议错误位置不同，不能声称原生根因已证明相同。

原始用例的只读阶段标记和几何采样没有从验收测试中移除。仍没有原生堆栈；新崩溃时间窗的 Windows Application 1000/1001 查询为零条，这不能排除渲染器、资源、驱动或应用原因。后续候选页在同一浏览器的新上下文中继续完成，不等于崩溃页自行恢复。

候选页为 330,091 字节，保留完整产品 CSS 和真实收入滚轮 DOM，删除其他卡片及产品脚本，仅用小型合成循环驱动数字。已核对截图非空和数字持续运动，但它没有触发崩溃，也未覆盖真实业务交接，不能提交为已确认的独立最小复现，更不能据此排除滚轮或 CSS。

初版控制命令的标题筛选未命中用例，记录为零执行、退出 1，不算失败用例或崩溃。修正筛选后仅执行一次有效控制，没有覆盖原日志。初版诊断包装器虽捕获崩溃却退出 0；此退出码不是质量门，后续脚本已改为实验失败即非零退出，本次结论取自事件、追踪与逐组结果。没有运行至通过或通过重试隐藏失败。

## 下一步

先缩减已失败的“前置同页负载 + 新上下文 + 恢复窄屏”路径：分别控制前置负载、只读采样和主题/实时交接，每组预先固定次数，出现失败即保留现场。再逐项移除非相关 DOM 或渲染效果，只有缩减后仍触发同类页面崩溃，才将其升级为可供上游定位的独立最小复现。
