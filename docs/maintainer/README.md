# 项目维护者入口

面向负责仓库、日历、交付和发布的维护者。具体规则只在原文档维护，此页不定义第二套版本规则。

## 常用职责

| 工作 | 权威入口 |
| --- | --- |
| 分支、PR、质量检查与文件命名 | [仓库维护策略](../REPOSITORY_POLICY.md) |
| V3、V4、V5 大版本发布约定 | [当前发布约定](../REPOSITORY_POLICY.md#当前发布约定) |
| 每年手动替换内置日历 | [年度日历清单](../calendar-maintenance.md) |
| Word 说明书与校验书签 | [说明书维护](../manual-maintenance.md) |
| 当前与待验收事项 | [文档与验收索引](../README.md) |
| 全部文件用途 | [仓库地图](../repository-map.md) |
| 变更与历史版本 | [更新记录](../../CHANGELOG.md) · [版本说明](../releases/) |
| 安全问题报告 | [安全说明](../../.github/SECURITY.md) |

角色目录只提供阅读入口：四文件、scripts、tests、config、.github 及历史记录不迁移，不新增兼容副本。普通更新不创建 Release；发布前按权威规则获取所有者确认。
