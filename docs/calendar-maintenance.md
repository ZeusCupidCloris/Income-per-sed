# 年度内置日历替换

每年手动更新，不增加在线同步或日历备份功能。

1. 依据正式公布的年度安排更新 Develop 的内置日历覆盖范围、版本、节假日和调休日期，按现有清单生成方式同步指纹。
2. 同时更新 IncomeWidget.js 的 HOLIDAYS 和 SPECIAL_WORKDAYS；不要只修改年份文字。
3. 运行 `npm test`。widget-parity.spec.js 自动检查完整日期集合、重复日期、覆盖范围和两类日期冲突，并核对两端计算。测试通过只代表内部一致，不替代对官方安排的人工核对。
4. 用新年份的实际工作日、调休周末、节假日和月末补充计算案例；保留历史案例用于验证兼容性，必要时明确其覆盖年份。
5. 运行现有发布准备流程生成 Push、同步校验值。发布前分别核对页面和小组件中的新年份结果。

这些校验运行于仓库测试环境，不会在页面内增加设置项。小组件测试以 Intl 模拟 Scriptable 日期格式化接口，不代表真实 iPhone 渲染或刷新验收。
