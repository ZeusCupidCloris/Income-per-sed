# Income-per-sed v2.5.2

本版本完成主题切换与输入动效的发布收口，页面视觉、收入计算规则和主表盘机械结构保持不变。

## 更新内容

- 浅色与深色主题使用左上至右下的对角材质过渡，反向切换采用相反方向。
- 主题切换期间主表盘尺寸、三根指针长度、数字滚轮和任务码表保持连续。
- 快速连续切换主题时，新选择会立即接管并取消旧过渡。
- 弹性方格背景在静止后停止刷新，鼠标经过时仍保留局部弹性反馈。
- 增加传统鼠标滚轮、触控板式连续输入、触屏拖动和 60Hz/120Hz 轨迹一致性验收。
- 更新 Word 使用手册、预览图、发布清单和 SHA-256 校验值。

## 验证范围

- Windows Edge 桌面与 390、768、1440、2560 像素布局。
- WebKit iPhone 尺寸启动与快速回溯面板。
- 鼠标滚轮、触控板式反向输入和触屏拖动自动化路径。
- 60Hz 与 120Hz 数值积分终点一致性。
- Push 可重复生成、Word OOXML、README 图片及正式文件校验。

自动化测试不能替代真实 iPhone、真实触控板与具体高刷新率显示器的主观手感判断；这些设备仍建议作为发布后的人工体验复核。

## 文件选择

- 日常使用：`Income-per-sed-Push.html`
- 开发诊断：`Income-per-sed-Develop.html`
- iPhone 小组件：`IncomeWidget.js`
- 完整说明：`docs/Income-per-sed（说明文档）.docx`

下载后可使用 `SHA256SUMS.txt` 核对文件完整性。
