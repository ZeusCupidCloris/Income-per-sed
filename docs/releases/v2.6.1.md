# Income-per-sed 2.6.1

四文件统一为 2.6.1，交付编号 20261008.1。本批通过 PR 同步仓库与 Pages，不创建 Release 或标签；远程完成状态以对应 PR 和 Actions 结果为准。

## 修复范围

中号小组件原先需要 82pt 表盘 + 16pt 间距 + 212pt 读数区，共 310pt。329pt 容器扣除左右各 16pt 内边距后仅有 297pt，已在新增断言中复现失败。

将读数区改为 199pt，使内容总宽度为 297pt。表盘尺寸、间距、常规金额 32pt 数字与 22pt 单位不变；长金额继续沿用原有缩略与适配规则，必要时较早进入紧凑显示。小号、大号及业务函数不变。此结论覆盖所测 329、342、400pt 容器，不代表所有设备实机排版已通过。

Develop 仅更新产品与交付元数据；Push 由 Develop 生成。使用手册、首页版本、发布清单和校验值同步更新，不改网页样式、动效或计算。
