# 2.8.0 组件化维护

交付编号：20261112.1。候选于 2026-11-12 准备，仅提交独立 PR 审核；不替换桌面文件、合并 main、部署或创建 GitHub Release / 标签。

## 使用方式

日常仍打开同批次的 Push 单 HTML，离线也能用。工资、工时和日历仍在浏览器本地保存，可用手册中的完整备份步骤迁移到其他浏览器。小组件仍按原方式使用，版本标识与网页和手册同步。

修复了日期估算切页后选中日期可能回跳、回溯已工作时长少一秒，以及趣味换算卡宽度误判。计薪规则、字体和机械动效不变。

## 维护入口

从 [src/page.html](../../src/page.html) 与 [组件目录](../../src/components/) 查找源码。首页读数、回溯面板、收入设置和工时设置有各自的修改入口；计薪和保存等共用规则不在各卡片重复。机械主表盘与时间轴动效未拆分。

生成时把结构、样式、脚本和数据装进两份 HTML；打开后不读取组件源码。详见[组件维护计划](../maintainer/component-architecture-2.8.md)和[候选验收](../acceptance/fourfile-20261112.md)。
