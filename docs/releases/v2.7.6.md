# 2.7.6 稳定性收尾

交付编号：20261101.1。当前为交付候选，检查、桌面替换与线上状态见[本批验收](../acceptance/fourfile-20261101.md)。

## 用户能感受到的变化

- 保存失败会明确保留失败状态，不再让其他窗口以为新工资已经保存。
- 日期与作息按北京时间计算，不受设备时区和夏令时跳时干扰。
- 窄屏回溯面板的键盘操作保持在面板内。
- 月收入长金额完整显示；趣味换算的数量和商品名称不拆字，普通数量恢复原布局和间距。
- 趣味卡在窗口变宽再缩回时保持文字可见。
- 进度卡内已经不可见的旧辅助标记不再参与布局，避免延迟更新时仍用宽屏坐标撑宽窄屏页面；实际连续游标和机械动效不变。

同帧日期分量复用减少重复工作，不增加跨帧缓存。字体、计薪公式、机械动效与小组件行为保持不变；Widget 仅同步交付标识。

此前自动化 WebKit 原生崩溃仍未归因，不因为本轮卡片空白修复就称其已解决。真实手机、真实整夜和实际读屏验收仍按原约定暂缓。不创建 GitHub Release 或标签。

2.8.x 将以[组件维护计划](../maintainer/component-architecture-2.8.md)为后续重构起点；本批不开始拆代码。
