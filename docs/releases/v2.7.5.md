# 2.7.5 午休进度衔接补丁

交付 20261028.1，日期 2026-10-28。

## 变化

从上午或午休回溯时刻返回实时，填充条和游标现在沿同一条路径经过午休空档，避免填充已进入下午、游标却仍在午休区的割裂感。复用已有前台恢复路径计算，保留计薪口径、返回总时长、状态机、尺寸兜底与缓存，不修改字体、布局、指针或机械滚轮，也不新增产品依赖。

新增双版本、两种宽度的午休边界与缩放回归，原有用例和 2.5px 贴边阈值不变。上一轮已先在旧产品复现，再以同一测试验证修复；这不替代本次冻结交付候选的完整业务验收。

本次完整验收另外捕获已有的前台恢复收尾主针回退。999ms 受控边界在 2.7.4 和候选上同样失败；收尾保留当前连续角度相位，而不是提前截成整秒，下一整秒仍由既有跳针接管。恢复曲线、总时长、分时针和滚轮不变。新增断言直接读取实际主针 transform，覆盖 Develop 与生成 Push；原前台恢复测试不删改，并扩展到 WebKit 完整范围。

## 四文件与验收

Develop 是唯一维护源，Push 由原工具生成；Widget 只同步交付标识。手册保留用户操作正文及准确的旧插图来源，只更新版本、交付号和校验书签。完整检查、桌面备份替换、远程 PR / main / Pages 的实际结果见[本批验收](../acceptance/fourfile-20261028.md)，各阶段单独记录。

## 边界

不创建 Release 或标签。面板高度变化后测量用例的偶发时序不稳定仍保留为独立风险；固定 WebKit 依赖环境不等于已经解决页面渲染问题。真实手机、真实跨夜与实际读屏验收继续暂缓。
