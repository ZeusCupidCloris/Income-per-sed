# Income-per-sed 2.6.0

四文件统一版本为 2.6.0，交付编号为 20261007.1。此次通过 PR 同步仓库与 Pages，不创建 GitHub Release 或标签。

## 更新内容

- 纳入用户已确认的小、中、大号小组件布局：统一金额字号与单位间距，突出状态图标，右上角显示数据更新时间，简化下一节点，完成后以已工作替代重复金额。
- 大号保留居中的表盘与读数，并使用淡色刻度进度轨道。
- 保留正式小组件的设置菜单、配置校验、安全保存、计算与网页入口，不使用只读预览入口。
- 网页 Develop 仅更新发布元数据，Push 从本次 Develop 生成。主表盘、数字滚轮、背景网格、主题切换及既有动效保持不变。
- 使用手册同步说明与两张中号模拟图片，保留网页参考图的原来源日期；发布清单、校验值、首页版本与截图来源一起同步。
