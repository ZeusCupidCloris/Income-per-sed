# 2.6.2 rc47 四文件同步

产品版本 `2.6.2-rc.47`，交付 `20261021.2`。这是本地候选交付，不代表已创建 GitHub Release、标签或更新 Pages。

## 用户能看到的变化

- 工资、工时和快速回溯使用完整面板，保留 RC37 字体方案和已确认的机械显示。
- 回溯明确区分暂停、播放、回到实时和关闭；跨日期时文案跟随所看日期。
- 任务码表显示任务计价、计时中或已暂停；表冠归零后有五秒撤销。
- 工资模式分别保留草稿；刷新后恢复需确认，恢复后仍需保存。
- 完整备份覆盖工资、工时和日历，导入前只比较变化项并保留金额保护。
- 使用手册按场景介绍怎么用，以及午休轨道、即时结果、费率锁定、撤销和导入对比的设计考虑。

## 四文件范围

Develop 同步已确认的 RC47，增加构建所需诊断标记并更新交付日期；Push 自动生成。小组件核对共享计算和内置日历，原有布局、设置读写与业务函数保持不变，只同步版本标识。手册重写并替换受影响插图，保留三份源文件的命名校验书签。

同步时发现并修复生成链路的两处问题：独立压缩的脚本把私有变量提升为同名全局变量；一个有效日期回溯入口漏标开发诊断调用。构建和验证现在拒绝残留诊断引用，并检查经典脚本的共享作用域。

## 验证与交付边界

生成版关键专项通过 Edge 18 项、WebKit 15 项；网页与小组件计薪及日历一致性在 Edge 的三项专项中核对。RC47 预览的 117 组检查是另外保存的证据，不冒称本次已重跑所有仓库历史套件。

本批检查、手册分页和重复构建结果见[同步记录](../acceptance/fourfile-20261021.md)。实体设备、真实跨夜及远程发布未在本批完成。历史正式 Release 与标签不修改。
