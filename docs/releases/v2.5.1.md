# Income-per-sed v2.5.1

这是一次仓库治理与发布可靠性更新，页面视觉和收入计算行为保持不变。

## 更新内容

- Develop 成为唯一维护源，Push 改为可重复生成的正式发布产物。
- 增加统一版本清单、标签归属校验和交付文件一致性检查。
- 增加 Safari/WebKit 手机版基础测试及失败诊断文件。
- 自动取消同一分支中过期的检查任务。
- 完善 Pull Request、依赖更新、分支保护与自动删除分支策略。
- 明确仓库仅用于公开展示，保留全部权利。

## 文件选择

- 日常使用：`Income-per-sed-Push.html`
- 开发诊断：`Income-per-sed-Develop.html`
- iPhone 小组件：`IncomeWidget.js`
- 完整说明：`Income-per-sed.docx`
