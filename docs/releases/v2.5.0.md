# Income-per-sed v2.5.0

这是 Pocket Watch v35 / R35 的正式发布版本，包含网页版、开发诊断版、Scriptable iPhone 小组件和完整 Word 说明书。

## 下载选择

- `Income-per-sed-Push.html`：日常使用与分享。
- `Income-per-sed-Develop.html`：诊断、维护和后续开发。
- `IncomeWidget.js`：Scriptable iPhone 桌面小组件。
- `Income-per-sed（说明文档）.docx`：完整使用和维护手册。
- `SHA256SUMS.txt`：校验下载文件完整性。

## 本版重点

- 主表盘历史回溯、播放和返回实时动画进一步连续化。
- 历史播放在页面进入后台后继续按真实时间推进。
- 数字滚轮保持顺滑追值，并改善后台恢复时的卡顿。
- 优化移动端快速回溯面板、码表指针层级和响应式布局。
- 完善浅色、深色和跟随系统主题。
- 更新 iPhone 中号小组件的信息层级与表盘布局。

## 数据与隐私

页面为单文件离线应用，不包含账户系统、后台服务或数据上报。设置保存在当前浏览器、设备本地或用户自己的 iCloud Drive 中。
