# R44 刷新交接修复验收 · 2026-09-07

## 先复现后修改

在 Edge 中以正常动效打开未修改的 Develop，使用持续前进的可控时钟，分别观察工作日 10:30 和 14:30。没有通过降低动效或启用减少动态效果规避问题。

14:30 场景的启动节点最大偏差约 358.9px；滚轮在启动交接后的采样中停滞约 191ms。修复后的相同场景节点偏差不足 1px，未观察到交接停滞。这是本次环境的复现记录，不是跨设备帧率保证。

## 修复范围

- 启动状态下取消节点独立的 CSS 位移过渡，跟随脚本计算的填充末端。
- 启动和实时滚轮使用同一轨道定位方式，避免整圈重置。
- 启动终点计入实时滚轮已有的 220ms 显示延迟，保留终点速度，避免实时目标追赶已显示数值。
- 主针启动结束对齐正常秒刻度；滚轮最终写入在切换 LIVE 所有权后提交。
- 不修改正常实时秒针的既有节拍、页面材质、滚轮外壳或小组件。
