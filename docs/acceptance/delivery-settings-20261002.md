本机 Edge、两种卡片各四次开合的单轮对比：样式计算耗时约 2.16s 降为 0.71s；帧间隔第 95 百分位约 29.2ms 降为 20.7ms；超过 34ms 的长帧从 22 帧降为 11 帧。主要改动是直接更新目标元素透明度，避免继承 CSS 变量逐帧引发子树样式重算，另为临时外壳使用合成层平移和布局隔离。未改变透明度曲线、材质参数和回弹轨迹。

数据是单机观察，不能保证所有设备达到相同帧率。`settings-frame-budget.spec.js` 只采样开销和检查清理，不以固定内存或帧率阈值判断所有机器。
