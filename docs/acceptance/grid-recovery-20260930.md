# 后台恢复绘制循环检查

## 范围

在交付 `20260930.1` 的 Develop 和 Push 上补充自动测试。首次专项仅修改测试、WebKit 测试入口和维护记录；四文件、背景绘制代码、视觉参数、截图基线均未修改。本文保留首次本地专项证据，后续完整回归、合并与发布状态见 [验收索引](../README.md)。

## 检查方法

测试在页面脚本启动前观察原生 requestAnimationFrame、cancelAnimationFrame 和背景画布 clearRect；从实际绘制识别网格回调，不依赖压缩前后的函数名称。

每个版本连续模拟十轮后台与前台切换，每次重复派发五次恢复通知，并交叉触发窗口尺寸通知与鼠标输入。断言后台待执行帧为零、后台绘制次数不增加；恢复后绘制继续、鼠标能够改变画布；全程最多一个网格待执行帧、只有一个网格回调身份。离开后等待原有弹性自然收敛，再观察 800ms，要求完全不再绘制。

检查依据是待执行帧数量及实际绘制，不把同一时间戳当作同一次浏览器帧的唯一标识。WebKit 在此环境中的自然回弹超过初始 8 秒观察窗口，延长观察确认最终静止；20 秒仅为自动测试等待上限，不是新的动画时长要求，未调整运行参数。
