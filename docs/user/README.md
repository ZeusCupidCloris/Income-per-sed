# 日常用户入口

只想使用网页或小组件，从这里开始。无需安装仓库的开发依赖。

## 推荐阅读顺序

1. [首页快速使用](../../README.md#快速使用)：下载 Push，设置工资和工作时间。
2. [Income-per-sed 使用手册](../Income-per-sed（说明文档）.docx)：小组件安装、功能说明、设置及故障排查。
3. [当前版本与四文件](../../README.md#当前版本)：核对产品、组件和交付编号，避免混用不同批次。

## 文件选择

| 文件 | 何时需要 |
| --- | --- |
| [Push 网页](../../Income-per-sed-Push.html) | 日常使用，可离线打开 |
